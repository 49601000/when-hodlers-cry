# when-hodlers-cry

『ホドラーのなく頃に』(WHEN HODLERS CRY) の**プレイ用リポジトリ**。
開発エンジン（ソース正本）は `49601000/when-hodlers-cry-dev-engine`。ここにはコンパイル済みの出力だけを置く。

**非公開・個人利用のパロディ作品専用。** 配信は GitHub Pages を使う（URLを配布しない運用。オーナー定義により実質非公開として扱う）。

## 遊び方（スマホ）

GitHub Pages のURLをスマホのブラウザで開き、ホーム画面に追加するとスタンドアロンで遊べる（PWA対応）。

- iPhone: SafariでURLを開く → 共有ボタン →「ホーム画面に追加」
- Android: ChromeでURLを開く → メニュー →「アプリをインストール」

初回ロード後はオフラインでも起動できる。セーブ／エピソード解放の進捗は、インストールしたアプリの localStorage に保存される（ブラウザを閉じても残る。端末・ブラウザを変えると引き継がれない）。

PCで遊ぶ場合は、このリポジトリを clone して静的サーバで開いてもよい（`npx serve .` 等）。

開発用：URL末尾に `?unlock=all` を付けると全EP解放表示で起動する（進捗データ自体は書き換わらない）。

## 収録内容

- 第1章「消える流動性」（鬼隠し編）— スペース版からの移植
- EP選択画面＋アンロック方式（次話は前話クリアまで表示されない）
- 立ち絵は全EP共通アセット（表情差分＋衣装差分対応）

## 操作

- タップ／クリック／Space／Enter：文章送り
- 画面上のボタン：バックログ／オート／スキップ／セーブ／ロード／環境音ON-OFF
